Still Present · iPhone

A new lock screen, every day.

iPhones don't let apps change the wallpaper, but Apple's own Shortcuts app can, on a schedule. Set it up once. It takes about 2 minutes.

Fastest way: get the ready-made Shortcut, then do step 3 below.

Get the Wallpaper Shortcut

1 · Wallpaper link

Today's wallpaper

This is what the link gives right now. It changes by itself. Step content never goes past the chosen step.

2 · Build the Shortcut

  1. Open the Shortcuts app. Tap + (top right) to make a new shortcut.
  2. Tap Add Action, search Get Contents of URL, and add it. Tap the blue URL placeholder and paste the link.
  3. Search Set Wallpaper Photo (on older iOS: Set Wallpaper) and add it. It uses the image from the step before automatically.
  4. In that action, choose Lock Screen only (on the home screen, app icons would cover the quote). Tap the small arrow › and turn Show Preview off (and Crop to Subject off, if it's there).
  5. Tap the name at the top, call it Wallpaper (a neutral name keeps it private), then tap Done. Tap it once to try it. The first time, iPhone asks to allow access. Tap Always Allow.

3 · Make it automatic

  1. In Shortcuts, open the Automation tab. Tap + (or New Automation).
  2. Choose Time of Day. Pick a time, e.g. 6:00 AM, and Daily. Choose Run Immediately (not "Run After Confirmation") and turn off Notify When Run if preferred.
  3. Tap Next, then pick the Wallpaper shortcut. Done.
  4. Chose "every hour" or "every 3 hours"? Add one more Time of Day automation for each time a change is wanted (e.g. 9 AM, 12 PM, 3 PM, 6 PM, 9 PM).

On iOS 27 the automation can also be created from inside the shortcut: open it, tap ⓘ › Automation. If a setting is called "Allow Running When Locked", turn it on.

Optional · Urge hours

If certain hours are hardest, like late Friday night, Still Present has a stronger Pause wallpaper. Make a second shortcut the same way with this link, and give it a Time of Day automation at the start of the hard hours. The normal automation switches it back the next time it runs.

Put Still Present on the home screen

  1. Open stillpresent.pages.dev in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open it from the icon. Reflections, saved quotes and Urge Mode live there, on the phone only.
