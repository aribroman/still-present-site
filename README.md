# Still Present — Public Web App & Recovery Hub

**Live site:** https://aribroman.github.io/still-present-site/

This public repository hosts the static build of **Still Present** (v3.6.20 PWA), the public Privacy Policy (`/privacy/`), Account Deletion page (`/delete/`), iPhone setup guide (`/iphone/`), and public read-only Recovery Hub data (`/hub/data/`).

- Private source code, Android project, Supabase migrations, and Cloudflare Pages `/sb/` proxy setup live in [`aribroman/still-present`](https://github.com/aribroman/still-present).
- No secrets, private keys, admin tools, or user data are stored in this repository.
